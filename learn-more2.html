How the estimator works

Data

The pipeline reads a documented CSV containing property characteristics and a target price in Moroccan dirhams. Synthetic demo rows are kept separate from future real market observations.

Preprocessing

District, property type and condition are one-hot encoded. Numeric and binary features pass through the same scikit-learn pipeline, which prevents training and inference from applying different transformations.

Model

A Random Forest regressor provides a strong, understandable baseline for nonlinear tabular data. A fixed train/test split produces MAE, RMSE and R² metrics. Metrics generated from synthetic data are explicitly labelled as demonstrations.

Limitations

This repository does not include verified Berkane transaction data. The demo model therefore cannot determine a property's real market value and must not be used for financial decisions.
